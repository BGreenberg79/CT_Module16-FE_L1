# Personal Dashboard App in Typescript
## Programmed by Benjamin Greenberg
Mini Project for Coding Temple

___
## Project Overview
This project works through advanced topics covered in Module 14 of Coding Temple's Frontend specialization. This project uses a typescript react project, GraphQL, and Apollo Client to build a robust personal dashboard app. In this app users can access user profiles, user posts, todo lists, and photo albums through GraphQL queries and mutations. 
___
## Installation Instructions
My program can be cloned from its [github repository](https://github.com/BGreenberg79/CT_Module14-FE_Miniproject) and then opened up using any web browser. These browser's may include Google Chrome, Miscrosoft Edge, Apple Safari, or Mozilla Firefox.
